# Visual perspective

Figures, tables, code, diagrams and interactive tools carry much of the teaching, and they fail in ways prose review misses. A table can be accurate and still unreadable; a figure can pass its model tests and still hide its outcome or contradict its caption. Both happened in earlier runs. This perspective judges what the reader actually sees, on the rendered page.

**Inputs:** the rendered pieces in a browser, at a fixed version; isolated figure routes where the coordinator provides them; the three reference articles' rendered figures and tables for comparison. If you cannot operate a browser, say so and ask the coordinator to operate the controls and report what happened, rather than inferring behaviour from source.

## Checks

1. **First reading alone.** Before reading the surrounding prose, look at each figure, table and code example, and use each interactive tool. Record what each seems to show and where you are unsure. That record shows whether it stands on its own. Then read it in place.
2. **Form fits the content.** Each item uses the form that shows its content most directly. Example data appears as rows under its real column headings, as the reader will meet it in a database. Each table column holds one kind of value. Relationships are drawn rather than described, and keys visibly connect across examples. Where a better form exists, name it: for instance, a small table per relation instead of a single table that packs each relation's columns into one cell as `name = value` lists.
3. **Readable at a glance.** No cell, caption or label needs decoding. Code examples are short, formatted and run in the order shown.
4. **Interaction.** Each control changes something meaningful. States and results are clear at every step, the explanation agrees with what is shown, and automatic playback leaves time to read all visible text. Keyboard use works, with focus kept on a control at its first and last step.
5. **Themes and phones.** Everything is readable in light and dark themes and at phone width, including comparisons that sit side by side on a desktop.
