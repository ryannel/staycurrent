# MongoDB — Research Log

## 2026-09-29 — cut v1

Founding run. Started from the non-relational facts gathered for the databases overview (8.2 release, WiredTiger basics, the 16 MB and 60-second limits, the SSPL date) and went deeper on every mechanism the deep-dive brief names.

Examined: the MongoDB manual pages on storage, WiredTiger, journaling, limits, write and read concern, replica set elections, the oplog, rollbacks, causal consistency, transactions and their production considerations, sharding (shard keys, ranges and the balancer, mongos routing, resharding), index types and index builds, time-series collections, change streams, and the 8.0 release notes; the `mongodb/mongo` replication README on GitHub; the MongoDB press releases for 8.0 (2 October 2024) and the 8.2 search announcement (17 September 2025); the SSPL text and licensing FAQ; the Delaware docket for MongoDB v. FerretDB; and third-party summaries of Atlas pricing and 8.3.

The proxy blocks `mongodb.com`, `source.wiredtiger.com`, `jepsen.io` and `endoflife.date`. The manual pages were read from the `mongodb/docs` source on GitHub where the file existed (limits, storage FAQ, WiredTiger, journaling, transactions, production considerations, shard key choice, data partitioning, elections, rollbacks, read isolation, index builds, mongos routing, resharding, time series, 8.0 release notes). The 8.2 and 8.3 release notes, the write concern and read concern reference pages, the oplog page, the Atlas pricing and limits pages, and the licensing pages were confirmed from indexed search content rather than fetched, and are flagged as such in the provenance. No lab measurements were run; every figure is a documented limit, a vendor claim, or a list price.

An editorial and accuracy pass was applied before publication: it corrected the binary-downgrade version to 7.0 and document validation to 3.2 (with `$jsonSchema` in 3.6), recomputed the 2 TB sizing question so the cache and disk arithmetic hold, added the range-migration mechanism and the full primary-secondary-arbiter stall, replaced the consistency-versus-availability interview question with the PSA one, cut the FerretDB case to a sentence, trimmed the performance envelope to numbers that appear nowhere else, added cross-links to the overview and sibling pieces, and removed the stock openers and closers the voice review named.
