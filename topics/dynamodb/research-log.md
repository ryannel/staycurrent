# DynamoDB — Research Log

## 2026-09-29 — cut v1

Founding run for the deep dive. Started from the facts gathered for the databases overview (quotas, transaction limits, the November 2024 price cut, MRSC GA, vector search GA) and went deeper on the 2022 ATC paper, the developer guide, and the 2025 to 2026 announcements.

The environment's egress proxy blocks aws.amazon.com, docs.aws.amazon.com, docs.amazonaws.cn, usenix.org, amazon.science, repost.aws, and every third-party blog tried, but allows GitHub. So: the ATC 2022 paper was read in full from a markdown copy at github.com/lambrospetrou/fokosdb; the current developer guide pages (quotas, partitions, capacity modes, warm throughput, transactions, GSI/LSI, vector search, global tables, streams, TTL, DAX, PITR, export, reserved capacity, key-range throttling, GSI throttling) were read from the mirror at github.com/groovy-sky/aws-docs, with older pages (write sharding, condition expressions, Query, adjacency lists, general NoSQL design, sparse indexes, GSI overloading) from the archived awsdocs/amazon-dynamodb-developer-guide repository; the October 2025 post-event summary was read from a verbatim copy at github.com/will62794/spectacle and the danluu/post-mortems index; the ExtendDB README and the AWS agent-toolkit DynamoDB skill (vector search reference and design rules) were fetched from GitHub directly.

Confirmed from indexed content rather than fetched: the What's New pages for the November 2024 price cut and warm throughput, the June 2025 MRSC GA, the February 2026 multi-account global tables, the May 2026 ExtendDB announcement, and the August 2026 vector search GA; the on-demand and provisioned pricing pages (rates cross-checked against an AWS-authored workshop page on GitHub for the pre-cut figures and the disaster-recovery page in the mirrored developer guide for the current replicated-write price); the 2012 press release; Alex DeBrie's one-to-many post; the ATC 2023 transactions paper; and the Database Savings Plans announcement at re:Invent 2025. The web search budget was exhausted partway through, so the remaining confirmations came from GitHub code search over mirrored documentation.

Not sourced to a primary page and stated as such or left out: the exact current Standard-IA request prices (third-party figures only), DAX node-hour prices (omitted), an SLA or figure for eventually consistent read lag (the docs say "after a short time"), and the exact date the multi-attribute GSI key feature shipped (described as "now documented").
