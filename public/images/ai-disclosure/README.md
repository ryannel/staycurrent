# EU AI disclosure icon

The black and white basic AI icons are unmodified files from the European
Commission’s SVG download, retrieved on 18 October 2026.

- Guidance and licence: https://digital-strategy.ec.europa.eu/en/policies/eu-icons-labelling-ai-generated-content
- SVG archive: https://ec.europa.eu/newsroom/dae/redirection/document/129546
- Original filenames: `LABEL_AI_black.svg` and `LABEL_AI_white.svg`

The Commission makes the icons freely available without requiring attribution.
Using them does not imply adherence to the Code of Practice or EU approval.
Stay Current pairs the basic icon with a visible AI-generated label and a link
to its explanation of the production and AI-agent review process.
