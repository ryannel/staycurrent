Read only the fields the report needs

Our shop has eight order records. Each contains country, total, customer, and delivery instructions. To add up sales by country, we need country and total from every order.

For this small model, every value occupies one cell and a disk page contains eight cells. The row layout packs all 32 cells into four pages. The column layout groups each field separately.

The row layout reads four pages. Storing the same records by column lets this query read just one page, saving 75% of the work. The report still includes all eight orders.

A separate index can help locate selected records. Adding one makes every query faster without giving inserts any extra work.
