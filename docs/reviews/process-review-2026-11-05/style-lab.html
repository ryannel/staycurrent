Six ways to draw a cache stampede

Each study animates the same moment from Handling cache misses. The blue mug's cached card has just expired, and four requests for it arrive within two seconds. With every caller reading for itself, the database does the same read four times. With one shared fill, it reads once and all four callers get that answer.

The timing, numbers and layout are identical across the six. Only the drawing changes, so you can judge the styles on look, legibility and feel. Use the theme switch to see each one in dark mode.

What to look for

  • Can you tell the four requests apart, and see where each one waits?
  • Is the answer's value (£20) readable wherever it travels? Our articles need values, not only shapes.
  • Does the dark version feel designed, rather than inverted?
  • Would it still feel right beside 3,000 words of careful prose, and on its fifth appearance in an article?
