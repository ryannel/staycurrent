# Analytics and time series: proposed coverage map

18 October 2026. Proposal for discussion within the [field plan](../databases-and-storage-plan.md),
before independent planning review or writing. Use the [shared map conventions](databases-and-storage.md#map-conventions).

An expert user can define what a report counts, choose a layout and execution
arrangement, ingest and correct data, handle time windows and late events, and run
the workload within resource and recovery limits. “Warehouse”, “lake” and “real
time” need operational meaning rather than separate vendor lists.

Running example: shop orders and line items, page-view events with stable event
IDs, and device D17's readings. Define report grain and event/source timestamps
explicitly. The existing 16-record page-view model remains the small layout
dataset; a larger measured dataset is separate and records its generation.
Base: `/learn/databases/analytics/`; retain the existing column-stores route.
