PostgreSQL can run these queries in different ways. It might look up each order’s lines in an index, or read both tables and match the rows as it goes. Its execution plan describes those operations, including how to group the rows and sort the totals. We’ll compare the plans for these two reports, then see what happens when PostgreSQL misjudges how many rows it will find.
