## Route-map revision: recognisable roles

The user preferred A and requested recognisable browser, Redis and server symbols.
The original “App A” meant the backend, but looked like a browser could talk to
Redis directly. A now shows four roles: North shop in a browser, shop server,
Redis cache and authoritative database. The server owns cache-aside. The browser
only sends requests to the server. The shared example's App A is relabelled “Shop
server” in this single-instance scene; no scenario facts change. B and C remain
earlier studies and their App A terminology is explained in the comparison intro.

The card contains a mug drawing and £20; it is built at the backend, copied to
Redis, and returned to the browser. On the second request the saved card stays in
Redis while a copy travels back. Server activity lights and brief arrival pulses
provide motion without requiring controls. Database read count remains one.
Redis is explicitly one possible cache implementation. Its current R symbol is
from https://github.com/simple-icons/simple-icons/blob/develop/icons/redis.svg
(CC0); it is rendered in the figure's theme-safe ink colour.
