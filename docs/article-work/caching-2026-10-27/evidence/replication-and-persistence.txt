Evidence for article 9, Redis replication, persistence and failover
Redis 8.10.3 (Homebrew, macOS arm64, libc malloc), Apple M3 Max laptop, 36 GB.
Ports: primary 7109; replicas and Sentinels 7190-7194. Every server started with --save '' --appendonly no and a temporary
directory under the session scratchpad; persistence was switched on per experiment with BGSAVE, CONFIG SET or --appendonly yes.
IMPORTANT CONDITION: the laptop was heavily loaded by other work throughout (load average 130-285 on 14 cores, swapping).
Times measured in seconds (Sentinel detection, timeouts) are unaffected at that scale; anything in milliseconds
(fork, load, fsync, WAIT, switchover duration) is noisy and must not be presented as typical.
kill -9 simulates a process crash; the operating system survives, so it does not test power loss (what fsync protects against).
Helper functions: scripts/lib.sh and scripts/sent.sh (reproduced at the end). Wall-clock times are in each server's log.

# A cache client that finds the primary through Sentinel and writes then reads every 100 ms.
# Logs one line per attempt: seconds since start, outcome, primary port. Usage: client.py OUTFILE DURATION
import sys, time, redis
from redis.sentinel import Sentinel
from redis.retry import Retry
from redis.backoff import NoBackoff
out, duration = sys.argv[1], float(sys.argv[2])
s = Sentinel([('127.0.0.1', p) for p in (7192, 7193, 7194)], socket_timeout=0.2, socket_connect_timeout=0.2)
m = s.master_for('cache', socket_timeout=0.2, socket_connect_timeout=0.2, retry=Retry(NoBackoff(), 0))
t0 = time.time()
with open(out, 'w') as f:
    f.write(f'# start {t0:.3f}\n')
    i = 0
    while time.time() - t0 < duration:
        t = time.time()
        try:
            m.set('heartbeat', i); m.get('product:42')
            port = m.connection_pool.connection_kwargs.get('port')
            try: port = m.connection_pool.get_master_address()[1]
            except Exception: pass
            f.write(f'{t - t0:.3f} ok {port}\n')
        except Exception as e:
            f.write(f'{t - t0:.3f} err {type(e).__name__}:{str(e)[:60]}\n')
        f.flush(); i += 1
        time.sleep(max(0, 0.1 - (time.time() - t)))
