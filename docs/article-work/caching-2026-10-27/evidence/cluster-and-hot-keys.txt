#   ConnectionError "client-side caching is supported by Redis 7.4 or later" when HELLO's server name is not "redis" or its version is lower.

#   addReplyBulkCString(c, server.extended_redis_compat ? "redis" : SERVER_NAME);     SERVER_NAME is "valkey" (src/version.h, 9.0.0)

# Redis 8.10.3 src/cluster_asm.c, asmTrimSlots(): active (main-thread) trim when server.tracking_clients != 0, because

#   connection periodically and flush the cache if pings stop coming back.
# Cluster specification: PFAIL after NODE_TIMEOUT; FAIL once a majority of masters report PFAIL/FAIL within NODE_TIMEOUT * 2;
#   the minority side refuses writes once NODE_TIMEOUT has passed without contact with the majority.
# Envoy Redis proxy documentation: Redis Cluster support (topology from CLUSTER SLOTS, MOVED/ASK handling, fragmented multi-key commands).
