########## Script t2.sh: the article's version script (copied verbatim into ver.lua), tombstones, NX hold-off, PUBLISH
local cur = tonumber(redis.call("HGET", KEYS[1], "version") or "-1")
local new = tonumber(ARGV[1])
local dead = redis.call("HEXISTS", KEYS[1], "value") == 0
if new > cur or (new == cur and dead and ARGV[2] ~= "") then
  redis.call("DEL", KEYS[1])
  if ARGV[2] == "" then redis.call("HSET", KEYS[1], "version", ARGV[1])
  else redis.call("HSET", KEYS[1], "version", ARGV[1], "value", ARGV[2]) end
  redis.call("EXPIRE", KEYS[1], ARGV[3])
  return 1
end
return 0

########## Sources read (text extracted or fetched 2026-10-27)
- Nishtala et al. NSDI 2013 PDF (pdftotext): 3.2.1 Leases (64-bit token; delete invalidates token; LL/SC; one token per 10 s per key; 'set of keys particularly susceptible to thundering herds for one week' 17K/s -> 1.3K/s; stale values); 4.1 (own-cluster invalidation for read-after-write 'As an optimization'; mcsqueal; 'only 4% of all deletes issued result in the actual invalidation of cached data'; replay of lost or misrouted invalidations); 4.3 cold cluster warmup, two-second hold-off rejecting add; 5 remote markers are per key k, set in a regional pool; eviction of markers impairs consistency; 'mcsqueal ... deployed with the replica databases'; buffered deletes replayed.
- Meta, Cache made consistent (2022): '99.99999999 percent of cache writes are consistent within five minutes'; fill/invalidation race; eviction loses knowledge of newer version.
- Debezium PostgreSQL connector docs: 'Debezium, like Kafka, provides at least once delivery of change events' during fault recovery; consumers should anticipate duplicates; LSN usable to detect duplicates.
- redis.io SET: IFEQ since 8.4.0; 'If the key doesn't exist, it won't be created'; condition options mutually exclusive (NX with IFEQ is a syntax error, observed).
- redis.io replication: asynchronous by default; WAIT 'does not turn a set of Redis instances into a CP system ... acknowledged writes can still be lost during a failover'.
- redis.io Pub/Sub: at-most-once; Streams offer at-least-once. Terry et al. 1994: four session guarantees incl. Read Your Writes. Rails guide: cache_key_with_version from updated_at; version stored in entry; touch: true.
- Valkey: SET IFEQ reported in Valkey 8.1 (mankier set.3valkey man page; secondary sources); DELIFEQ version unconfirmed.
