## S1. Independent XFetch simulation (scripts/xf.py; python3 -I xf.py 4000)
# Request by request; time in rebuild units; stampede = refreshes in [Z, Z+1) (paper Definition 3).
```
# Independent request-by-request XFetch simulation (reviewer). Time in rebuild units.
# A request at time t (expiry at 0, t<0 before) refreshes if t + Exp(mean beta) >= 0, or t >= 0.
# Stampede size = number of refreshing requests in [Z, Z+1), Z = first refresh (paper Def. 3).
import random, math, sys
def arrivals(rng, rate, start, kind):
    t = start
    if kind == 'even':
        t += rng.random()/rate
        while True:
            yield t; t += 1/rate
    elif kind == 'poisson':
        while True:
            t += rng.expovariate(rate); yield t
    elif kind == 'bursty':  # hyperexponential inter-arrivals, mean 1/rate, CV ~3.6
        p = 0.04; m1 = 0.5/rate*1/(1-p) ; m2 = 0.5/rate/p   # mixture with mean 1/rate
        while True:
            t += rng.expovariate(1/m2) if rng.random()<p else rng.expovariate(1/m1); yield t
def cycle(rng, rate, beta, kind):
    start = -beta*math.log(rate*beta/1e-9) - 5
    Z=None; S=0; late=False
    for t in arrivals(rng, rate, start, kind):
        if Z is not None and t >= Z+1: break
        if t >= 0 or (t + rng.expovariate(1/beta)) >= 0:
            if Z is None: Z=t
            S+=1
    return S, -Z
rng = random.Random(20261027)
N=int(sys.argv[1]) if len(sys.argv)>1 else 4000
print("kind rate beta  meanS  e^(1/b)  paper(e^l-1)(1/l+1/e)  meanLead  formula_lead")
for kind in ['poisson','even','bursty']:
  for rate in [10,100,1000]:
    for beta in [0.5,1,1.5,2]:
        if kind!='poisson' and beta in (0.5,2) and rate!=100: continue
        tot=0; lead=0
        for _ in range(N):
            s,l = cycle(rng, rate, beta, kind); tot+=s; lead+=l
        lam=1/beta
        print(f"{kind:7s} {rate:5d} {beta:4.2f}  {tot/N:6.3f}  {math.exp(lam):6.3f}  {(math.exp(lam)-1)*(1/lam+1/math.e):6.3f}  {lead/N:6.3f}  {beta*(math.log(rate*beta)+0.5772):6.3f}")
```

## S2. Paper: Vattani, Chierichetti, Lowenstein, PVLDB 8(8) 2015, https://www.vldb.org/pvldb/vol8/p886-vattani.pdf
# Theorem 7: Exp(lambda) is ((e^l - 1)(1/l + 1/e), (1/l) log n)-effective. Definition 5: (s,g)-effective means E[S] <= (1+o(1)) s. XFetch uses D = Exp(1/beta).
# Section 3: 'for lambda = 1 ... stampedes of size e - 1/e' ... 'merely e - 1/e ~ 2.4 processes'.
# Appendix, proof of Lemma 16: 'By Claim 21 and the fact that E[S | T in (nu-i-1, nu-i)] <= n e^{-lambda(nu-i)} = e^{lambda i}'.
#   Given T (early expiration gap), the stampede window covers y in (T-1, T]; refresh probabilities there are in [e^{-lT}, e^{-l(T-1)}],
#   all >= e^{-lT} > e^{-l(nu-i)}. Exact conditional mean (Poisson) = (n/l) e^{-lT} (e^l - 1) > e^{li} (e^l-1)/l > e^{li}. The step under-counts.
# Section 6 (Goodreads trace: interarrival 0.07 s, sd 0.25 s, sigma_I ~3.6, n ~140): Figure 7 rendered at 400 dpi: Exp curve ~3 at beta=1, ~8 at beta=0.5,
#   crosses y=2 near beta=1.5; text: 'increasing beta = 1/lambda to 1.5 already drops the average stampede size to less than 2'.
# Ratio bound/e^l = (1-e^{-l})(1/l+1/e) < 1 for all l>0 (0.865 at l=1, 0.932 at l=0.5, -> 1-0.132 l as l->0).
