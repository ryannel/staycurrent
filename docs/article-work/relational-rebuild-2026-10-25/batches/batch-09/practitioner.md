## Coverage and supporting observations

- **Bounds and ordering:** The three-key trace separates entries examined, rows fetched and sort input. Its customer-only, customer-leading and time-leading paths return the same two orders with 4/4, 2/2 and 6/2 entry/fetch counts respectively. Later-column rejection is distinguished from shortening traversal, and skip scans/repeated searches qualify the hand trace. Equality-column order is considered across the workload. Reverse scans, mixed directions, null placement, collation, explicit `ORDER BY`, ID ties and the aggregate-report limit counterexample are accurately bounded.
- **Coverage, partial membership and expressions:** Status payload saves table work without becoming a search bound. The visibility qualification is present before the covering comparison. The paid-only partial index is explicitly unable to replace all-status history; unknown generic-plan parameters are distinguished from known custom-plan values. The direct UTC interval and UTC-date expression ask the same question; the session-dependent bare timestamptz-to-date conversion is excluded. The SQL definitions match these explanations.
- **Placement and workload:** Figure 3 distinguishes row fetches from distinct table pages, labels both layouts as invented and omits index/caching/storage work explicitly. Bitmap order loss and broad sequential scans prevent a universal selectivity threshold. The workload section considers shared prefixes, foreign-key reverse lookups, existing order-line keys, narrower alternatives, uniqueness and rare jobs before removal. It does not infer that every apparent prefix duplicate can be dropped.
- **Maintenance:** The pending-to-paid example separates unchanged key, changed payload and entering a predicate. The subsequent HOT qualification prevents readers from assuming that unchanged key values always avoid native index work. Width, cache, logging, splits, insertion pattern and eventual cleanup are treated as costs to measure, without invented write-amplification numbers or production acceptance.
