## Verification and handoff

Record findings and repairs in the relevant batch notes. Distinguish SQL observed
in PGlite from multi-session server experiments, and illustrative schedules from
executed behaviour. Browser PostgreSQL cannot demonstrate real replication,
disk-loss recovery or independent concurrent server connections. Where those are
the subject, pair honest sandbox exercises with concrete server procedures.

No stage is complete merely because it builds. Publication requires the finished
reading, independent challenge, resolved material findings and checked examples.
